# 向北 · 七日北欧神话读本

第一周的中文北欧神话入门网站。七篇原创入门改写，从创世到诸神黄昏；每篇提供人物提示、思考问题、版本说明和免费英文原典链接。

## 网站

https://imuxlucas.github.io/northward/

## 本地运行

无需依赖或构建。在此目录运行：

```sh
python3 -m http.server 8765
```

访问 http://localhost:8765 。

## 内容与文件

- `content.js`：七篇故事、人物、问题、出处。
- `index.html`：首页、阅读区与原典书架。
- `style.css`：电脑与手机排版。
- `app.js`：日期导航、已读进度、笔记保存与文本导出。
- `.nojekyll`：GitHub Pages 直接提供静态文件。

正文是根据中世纪神话材料编写的现代中文短篇改写，并非古诺尔斯语直译，也未转载现代中文出版物。主要参考斯诺里《散文埃达》（Brodeur 英译，1916）与《诗体埃达》（Bellows 英译，1923）；具体篇章与版本差异在页面中标注。

当前分支已实现可配置的 Google 登录与云端进度同步，项目配置尚未完成。游客记录兼容旧 localStorage；登录后按账号隔离，只同步已读状态与上次阅读位置，笔记仍保存在本机。配置和上线前检查见 [AUTH-SETUP.md](AUTH-SETUP.md)。

## 发布

GitHub Pages 使用 `main` 分支根目录发布。更新文件后推送即可重新部署。所有本地资源使用相对路径，适配项目子路径。

## 验证

已验证七篇切换、刷新后进度/笔记保留、撤销已读、文本导出、原典说明展开，以及手机宽度下无横向溢出。内容修改后可先用 `node --check app.js` 与 `node --check content.js` 检查语法。
